# TENGELO

**The easiest way to buy grains in Zambia**

Cashless, fast, and reliable — buy directly from farmers and aggregators through a few taps. From the field to your marketplace — here to buy from you, the easy way.

## About TENGELO

TENGELO is a comprehensive grain trading platform designed specifically for the Zambian market. Our platform connects farmers, aggregators, and buyers in a seamless digital marketplace that makes grain trading simple, transparent, and efficient.

### Key Features

- **Cashless Transactions**: Mobile money integration with Airtel, MTN, and Zamtel
- **Direct Trading**: Buy directly from farmers and aggregators
- **Fast & Reliable**: Streamlined process from field to marketplace
- **Role-based Access**: Admin, Aggregator, and Farmer user roles
- **Real-time Notifications**: SMS notifications for all transactions
- **Comprehensive Analytics**: Transaction reports and market insights

### Technology Stack

- **Backend**: Laravel 11/12 (PHP)
- **Database**: SQLite
- **Frontend**: Blade Templates with Tailwind CSS
- **Payment Integration**: Mobile money services
- **Notifications**: SMS gateway integration

### Getting Started

1. **Installation**
   ```bash
   composer install
   php artisan migrate
   php artisan db:seed
   ```

2. **Run the Application**
   ```bash
   php artisan serve
   ```
